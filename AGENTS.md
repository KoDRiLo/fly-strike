# AGENTS.md

Орієнтир по проєкту для ШІ-агентів і розробників: що де лежить і як із цим працювати.

## Що це

«Небесний Шторм» — браузерний вертикальний скрол-шутер із роглайк-перками на Three.js. Чистий JavaScript (ES-модулі), без збирання. Усі ресурси (моделі, ландшафт, текстури, звук, музика) генеруються процедурно — у репозиторії немає жодного файлу з графікою чи аудіо.

Гра опублікована на GitHub Pages з гілки `main`: <https://kodrilo.github.io/fly-strike/>. Кожен пуш у `main` оновлює сторінку.

## Команди

```bash
npm install        # лише для лінтера; самій грі залежності не потрібні
npm start          # локальний сервер: http://localhost:8000
npm run lint       # ESLint
npm test           # тести чистої логіки (node --test)
npm run smoke      # димовий тест у headless Chrome: боси, перки, зброя, кінець гри
```

Через `file://` гра не запуститься: модулі та import map потребують HTTP. Кроку збирання немає — після зміни файлу достатньо оновити сторінку. Перед комітом мають проходити `npm run lint`, `npm test` і `npm run smoke` (останній потребує Chrome або Chromium; шлях можна задати змінною `CHROME`).

Режим налагодження: додайте `?debug` до адреси — з'явиться лічильник FPS і об'єкт `window.__game` (стан, гравець, функції появи ворогів і босів) для експериментів із консолі.

## Як модулі пов'язані

- Назва `three` розв'язується через import map в `index.html` на `./vendor/three.module.js`.
- `balance.js`, `perks.js`, `config.js` і `audio.js` не залежать від DOM-розмітки гри та Three.js; перші три можна імпортувати в Node — на них і написані тести.
- `core.js` → `state.js` → `fx.js` — основа без циклів; їх можна вільно використовувати на верхньому рівні модуля.
- Ігрові модулі (`enemies`, `bosses`, `player`, `targets`, `weapons`, `pickups`, `bullets`, `stage`, `perkui`, `settings`, `game`, `hud`) імпортують один одного по колу. Це працює, бо імпортоване використовується лише всередині функцій. **Не звертайтеся до імпорту з ігрового модуля на верхньому рівні іншого ігрового модуля** — отримаєте помилку ініціалізації.
- Імпортовані змінні доступні лише для читання. Стан, який змінюється ззовні, має функцію-сеттер у своєму модулі: `setHi()` у `state.js`, `clearBoss()` у `bosses.js`, `quietly()` в `enemies.js`. Ширина поля `W` змінюється лише в `core.js` (`resize`).
- Експорти кожного модуля зібрані в одному блоці `export { … }` наприкінці файлу.

## index.html

- Весь CSS — в одному блоці `<style>`.
- `#game` — контейнер із портретними пропорціями; у ньому `<canvas id="c">` та шари інтерфейсу.
- `#hud` — рахунок, рекорд, етап, кнопки звуку `#muteBtn` і паузи `#pauseBtn` (правий нижній кут), смуга боса, життя, міцність, досвід, кнопка бомби, повідомлення.
- Оверлеї (клас `.overlay`, ховаються класом `.hidden`): `#menu`, `#pause`, `#pick` (вибір перка), `#info` (довідник перків), `#settings`, `#over` (кінець гри).
- Модулі звертаються до елементів за `id` через `$()` з `core.js`, тому перейменування `id` потребує правки в обох місцях.

## Модулі гри

| Модуль | Що всередині |
| --- | --- |

| `state.js` | `S` — стан сесії, `P` — гравець (`freshPlayer()`), масиви `enemies`, `pBullets`, `eBullets`, `missiles`, `pickups`; `later()` — відкладені дії; `threat()`, `diff()`, `threatDmg()`, `xpNeed()` |

| `hud.js` | `ui`, `showMsg()`, `updateHud()`, `screenFlash()` |
| `enemies.js` | `DEF` (характеристики), `WAVES` (шаблони хвиль), `ELITE`, `spawnEnemy()`, `spawnWave()`, `eShoot()`, `updateEnemies()` |
| `bosses.js` | `BOSSES`, атаки `ATK`, `spawnBoss()`, `damageBoss()`, `updateBoss()`, поточний `boss` |
| `pickups.js` | `STARS` (рідкості), `dropStars()`, `gainXp()`, `updatePickups()` |
| `player.js` | `input`, `SPEED`, `hurtPlayer()`, `shockPlayer()`, `GUN`, `useBomb()`, `updatePlayer()`, моделі літака й дронів |

| `bullets.js` | `updateBullets()`: кулі гравця, ракети, ворожі кулі (зокрема з прискоренням і самонаведенням) |

Керування: літак рухається з клавіатури (WASD / стрілки) або пальцем; в обох випадках швидкість дорівнює `SPEED × P.spd`, щоб перк «Форсаж» діяв однаково. Миша літаком не керує — лише права кнопка для бомби.

Типові зміни:

- **Новий перк** — додати об'єкт у `PERKS` (`perks.js`): `id`, `cat` (`atk` / `def` / `util`), `icon`, `name`, `desc`, `max`, `apply(P)`; необов'язково `ok(P)` (умова появи), `w` (вага), `rare` (рідкісний, золотий) або `mid` (незвичайний, фіолетовий; вага `MID`). Гравець передається аргументом — модуль лишається чистим. Довідник і картки будуються з цього масиву; тести в `test/perks.test.js` перевіряють кожен перк.
- **Нова додаткова зброя** — поля у `freshPlayer()` (`state.js`), базовий перк середньої рідкості (`max: 1`) і покращення з `ok(P)` у `PERKS`, логіка й візуал у `weapons.js` (функція `update…(dt, on)`, виклик з `updateWeapons()`).
- **Новий ворог** — модель у `BUILD` (`models.js`), характеристики в `DEF`, поведінка в `updateEnemies()`, поява у `WAVES` (усе в `enemies.js`).
- **Новий бос або атака** — `BOSSES` і `ATK` у `bosses.js`, модель у `makeBoss()` (`models.js`). У кожного боса щонайменше три атаки, і жодна атака не повторюється в іншого боса.
- **Баланс** — формули й спільні константи (`BASE_MAGNET`, `SHIELD_RECHARGE`) в `balance.js`, `STAGE_LEN` у `state.js`, `ELITE` і `DEF` в `enemies.js`.

## src/models.js

Низькополігональні моделі з примітивів. Угода про осі: ніс моделі дивиться в +Y, верх — +Z.

- Допоміжні фігури: `cyl`, `cone`, `box`, `plate` (симетрична пластина за контуром половини), `canopy`, `flame`, `prop`.
- `addOutline()` — чорний контур методом «вивернутої оболонки».
- `BUILD` — конструктори ворогів: `scout`, `fighter`, `kami`, `gunship`, `strafer`, `emine`, `mine`, `bomber`, `spinner`, `ace`.
- Експорт: `makePlayer()`, `makeDrone()`, `makeEnemy(type)` (клонує кешований прототип), `makeBoss(kind)`, `setHeroColors(plane, drone)`, `makeStar()`, текстури на canvas `glowTexture()`, `powerTexture()`, `starTexture()`, `orbTexture()`.
- Деталі з іменами `flame` і `spin` анімуються з ігрових модулів.

## src/world.js

- Земля — три плитки, що прокручуються вниз і переставляються нагору. Кожна плитка — одна злита геометрія з кольорами у вершинах плюс одна для світних деталей, тобто два draw call на плитку.
- `Builder` — збирає фігури (`box`, `quad`, `pyr`, `ico`, `disc`, `cone`, `frustum`) у спільні масиви; `spot()` шукає вільне місце.
- Готові об'єкти: `palm`, `conifer`, `leafy`, `rock`, `house`.
- `BIOMES` — масив біомів (`name`, `ground`, `build(b)`): ОКЕАН, ЛІС, ПУСТЕЛЯ, МІСТО, ФЕРМИ, АРКТИКА, ВУЛКАН. Новий біом — новий елемент масиву.
- Експорт: `createWorld(scene)` → `{ name(i), setBiome(i, force), update(dt), debugEdge() }`, а також `CW`, `CH`, `GROUND_Z`, `BIOME_COUNT`.

## src/audio.js

- Усе синтезується на Web Audio: осцилятори (`tone`) і фільтрований шум (`noise`).
- Експорт: `initAudio()` (викликати після дії користувача), `setVolume(kind, v)` для `music` / `sfx`, об'єкт `sfx` (`shoot`, `missile`, `hit`, `boom`, `hurt`, `power`, `bomb`, `warn`, `star`, `level`, `zap`, `elite`, `clear`), об'єкт `music` (`start`, `mode`, `stop`, `preview`), `audioPause(paused)`.

## Збережені дані

`localStorage`: `skystorm_hi` — рекорд, `skystorm_cfg` — налаштування (гучність, увімкнення музики й ефектів, індекс кольору). Обидва читаються під час завантаження сторінки.

## Угоди

- Мова інтерфейсу та коментарів у коді — українська.
- Жодних зовнішніх ресурсів і залежностей у самій грі: нову графіку чи звук робити процедурно.
- Продуктивність важлива: усе, що часто з'являється (кулі, частинки, ракети, кільця, зірки, моделі ворогів), береться з пулів — не створювати меші в головному циклі.
- Стиль коду компактний: короткі імена для глобального стану (`S`, `P`), таблиці даних замість класів.
- Моделі босів кешуються в `bossModels` (`bosses.js`) і використовуються повторно; моделі ворогів — у пулах. Не створюйте нові геометрії під час гри без `dispose()`.
- Усе, що читається з `localStorage`, проходить перевірку (`sanitizeCfg`), перш ніж потрапити в гру.
- Звук на паузі: `audioPause(true)` виставляє прапорець, і `initAudio()` не відновлює звук від випадкового кліку.
- Шкода ворожої кулі передається аргументом у `eShoot()`, а не через спільну змінну.
- Критичний постріл визначається в `pShoot()` (`player.js`) у момент пострілу: куля береться з `critBulletPool`, а влучання показує `critHit()` (`fx.js`).
