# Небесний Шторм (fly-strike)

Аркадний вертикальний скрол-шутер із роглайк-перками, написаний на чистому JavaScript і [Three.js](https://threejs.org/). Без збирання, без залежностей із npm, без жодного файлу з графікою чи звуком: моделі, ландшафти, текстури, звукові ефекти та музика генеруються кодом.

**▶ Грати в браузері: <https://kodrilo.github.io/fly-strike/>**

## Про гру

Ви керуєте літаком, що летить над ландшафтом, який безперервно прокручується. Вогонь автоматичний — ваша справа ухилятися, збирати зірки досвіду й обирати перки.

- **Етапи.** Кожен етап — це близько 45 секунд хвиль ворогів, після яких з'являється бос. Перемога над босом відкриває наступний етап і новий біом.
- **Біоми.** Океан, ліс, пустеля, місто, ферми, Арктика, вулкан — змінюються по колу.
- **Вороги.** Розвідники, винищувачі, камікадзе, штурмовики, бомбардувальники, міни та інші; трапляються елітні вороги з посиленими характеристиками.
- **Досвід.** Зі збитих ворогів випадають зірки чотирьох рідкостей (1, 3, 8 і 20 досвіду).
- **Перки.** Новий рівень або перемога над босом дає вибір одного з трьох перків: атака (гармати, ракети, дрони, рикошет, критичний удар), захист (броня, щит, ремонт, запасний літак) та підтримка (бомби, швидкість, магніт, удача, досвід).
- **Складність** поступово зростає з часом гри.
- **Рекорд і налаштування** зберігаються в `localStorage` браузера.

## Запуск

Гра використовує ES-модулі, тому її потрібно відкривати через локальний вебсервер, а не як файл з диска (`file://`).

```bash
git clone git@github.com:KoDRiLo/fly-strike.git
cd fly-strike
python3 -m http.server 8000
```

Після цього відкрийте <http://localhost:8000> у браузері. Підійде будь-який статичний сервер (наприклад, `npx serve`).

Для розробки: `npm install`, далі `npm run lint` і `npm test`. Адреса з `?debug` показує лічильник FPS і відкриває стан гри в консолі.

Потрібен сучасний браузер із підтримкою WebGL, import maps і Web Audio.

## Технології

- **Three.js r170** — лежить у `vendor/`, підключається через import map.
- **WebGL** — рендеринг; моделі складені з примітивів, ландшафт зливається в одну геометрію на плитку.
- **Web Audio API** — процедурні звукові ефекти та музика.
- **HTML / CSS** — інтерфейс (HUD, меню, картки перків) поверх canvas.

## Структура проєкту

```

src/main.js             точка входу: керування та головний цикл

src/balance.js          формули балансу
src/models.js           3D-моделі та текстури
src/world.js            біоми й прокручуваний ландшафт
src/audio.js            звукові ефекти та музика
test/                   тести логіки
vendor/three.module.js  Three.js
```
